## 🚀 How to Deploy on Vercel in 2 Minutes

### Option A: Via GitHub (Recommended for monthly updates)
1. Create a new GitHub repository (e.g. `titan-indiranagar-offers`).
2. Upload the files from this directory (`index.html`, `app.js`, `offers.json`, `vercel.json`).
3. Go to [vercel.com](https://vercel.com) and click **"Add New Project"** &rarr; **"Import"** your GitHub repository.
4. Framework Preset: **Other** (Root directory: `./`).
5. Click **Deploy**. Your site will be live instantly with a free `.vercel.app` domain (or your custom domain like `offers.titanindiranagar.com`).

### Option B: Using Vercel CLI / Drag & Drop
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` inside this directory and follow the prompts.

## 🔄 How to Update Offers Every Month (Takes 30 Seconds)

You have **two simple ways** to update the offers each month:

### Method 1: Edit `offers.json` Directly
Open `offers.json` on GitHub and modify the text, discount percentages, or titles. Once saved, Vercel automatically deploys the updated version within 30 seconds!

### Method 2: Use the Built-in Offer Manager (On the website)
1. Scroll to the footer of the website and click **"Update Monthly Offers"**.
2. Update the Campaign Month Name (e.g. *"Diwali Festive Mega Sale"* or *"September Special Deals"*).
3. Tweak the JSON directly in the visual editor and click **"Preview on Page Now"** to see changes immediately.
4. Click **"Copy Updated JSON"** and paste it into `offers.json` in your GitHub repository.
